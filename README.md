> [!CAUTION]
> This software is obsolete. In recent versions of macOS, Spotlight started to allow opening of individual music files without opening the whole album.

# AlbumTagRemover
* Removes ID3 album tags (TALB) from music files so Spotlight opens individual files instead of the whole album in macOS.

# Dependencies
`pip3 install mutagen`

# Usage
`./id3_talb_remove.py ~/Music/folder [~/Music/more_folders]`
